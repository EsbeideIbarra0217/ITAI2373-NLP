# NewsBot Intelligence System

## Project Overview

The NewsBot Intelligence System is a Natural Language Processing (NLP) project developed for ITAI 2373. The purpose of this project is to analyze and process news articles using different NLP techniques.

## Project Objectives

- Preprocess and clean news articles.
- Categorize news articles using machine learning.
- Extract named entities such as people, organizations, and locations.
- Analyze sentiment and emotional tone.
- Identify patterns using TF-IDF, POS tagging, and syntax parsing.

## Technologies Used

- Python
- Google Colab
- Pandas
- Scikit-learn
- NLTK
- spaCy
- Matplotlib
